# Data Availability

This repository follows a curated public-artifact strategy.

Included in GitHub:

- source code;
- central configuration;
- selected publication figures;
- lightweight CSV samples;
- documentation for reproduction.

Not included in GitHub:

- third-party technical manuals;
- local Chroma databases;
- full experiment logs over typical GitHub file-size limits;
- submission cover letters and journal-specific template files;
- the paper PDF while the manuscript is under review.

The full experimental artifacts are intended for Zenodo or GitHub Release publication after paper clearance. Users who reproduce the study must provide their own licensed source documents and verify redistribution rights for any technical documentation used.
