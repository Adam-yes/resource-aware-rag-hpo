# Roadmap

## Near Term

- Strengthen config validation and runtime failure policies.
- Add context-window safeguards for large retrieval candidates.
- Expand unit tests around evaluation contracts, indexing idempotency, and early stopping.
- Publish PR-style change notes for major technical upgrades.

## Longer Term

- Add a multi-objective score that combines quality, latency, and compute budget.
- Persist the fitness archive across interrupted optimization runs.
- Render key notebooks into static documentation.
- Publish full reproducibility artifacts through Zenodo after paper clearance.
- Add richer observability for candidate failures and local model runtime behavior.

## Out Of Scope For The Public Repo

- Redistributing third-party technical manuals.
- Shipping model weights or local vector stores.
- Claiming full artifact reproducibility before data release.
